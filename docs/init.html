Viva Carta / Extendo — Internal Project Brief

The Reference Tool

A browser-based 3D artist reference system that maps real photography to camera angle. Built to replace what died. Built to last.

Philosophy
"Artists don't need more renders. They need to study reality. This tool is a window — not a generator."
01
Photos Only
No AI imagery. No 3D renders as references. Real light, real skin, real perspective. The whole point is studying what a camera actually captures.
02
Automation First
No manual tagging at scale. Head pose estimation does the work. The pipeline runs once, produces a JSON index, and the product is live.
03
Curation is the Moat
The code is not the product. The indexed, filtered, quality-controlled dataset is. That's what no one can copy quickly.
System Architecture
1
Data Layer — Ingestion
Source royalty-free portrait datasets. Start with FFHQ (70k faces, public domain). Pull a 100-image subset for the hello world test.
FFHQ LPFF Public Domain
2
Pipeline Layer — Pose Extraction
Python script that reads images, runs MediaPipe Face Mesh to extract Yaw / Pitch / Roll, applies blur detection (Laplacian variance), filters low-quality frames, and writes a JSON index file.
Python MediaPipe OpenCV NumPy
3
Index Layer — JSON Bucket Map
Each image maps to an angle bucket quantized to the nearest 15°. The key is yaw_{n}_pitch_{n}. Simple. No database needed. The whole index is one flat JSON file.
JSON 15° Buckets Yaw + Pitch + Roll
4
Viewer Layer — Three.js Interface
Modern Three.js (ES modules). OrbitControls on a 3D head mesh. On drag-end, read Euler angles, round to nearest bucket, fetch matching images from the index, render the photo grid.
Three.js OrbitControls ES Modules Vanilla JS
5
Deploy Layer
Static site. JSON index + images hosted on a CDN or Vercel. No backend needed for V1. Domain under Viva Carta — something clean and memorable.
Vercel Static CDN

Phase 4
The Moat
What anyone can copy
The Three.js viewer. The Python pipeline. The JSON structure. All of this is reproducible in a weekend if you know what you're doing.
What takes real work to replicate
A filtered, quality-controlled, diverse, richly-tagged dataset at scale. That's months of pipeline runs, calibration, edge case handling, and curation decisions. That's the product.
What ReferenceAngle didn't have
Secondary attributes. Lighting type. Focal length. Skin tone coverage. Age range. These transform it from a pose lookup into a real production reference tool.
The open source play
Publish the pipeline. Let people see the process. The tool builds trust. The dataset builds dependence. The community builds the brand.
